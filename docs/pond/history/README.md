# How the pond got built

**These are a record, not instructions.** They describe what was planned and
in what order — not how the pond works now. Where one of them disagrees with
a document in the folder above, the one above is right.

They are kept because the reasoning in them is sometimes still the answer to
"why is it like this", and that reasoning is not written down anywhere else.
