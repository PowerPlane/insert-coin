# The pond

The web half of BY-002 "Insert Coin". Tap the card, get a fortune, decorate
the duck you were dealt, and leave it in a pond that everyone else's ducks
are already floating in.

Live at `ducky.davidyang.work`. Not built yet — this directory is the design
and the decisions behind it.

## The prototype

`pond/tools/prototype-flow.html` — open it in a browser. Nine screens, the
real sprites, the real physics, the real copy. It is the reference for
anything the docs do not settle, and it is what gets reviewed.

Under the phone there is review-only scaffolding (**Add 100 ducks**) that
exists so the camera has something to do; it is not part of the product.

## The code

```
pond/
  schema/       SQL. One migration, heavily commented — the comments are the
                design rationale, not decoration.
  src/worker/   Server. Written against SQLite; ports to Turso unchanged.
  src/client/   Sprites, rendering, codec. Shared with the prototype in
                spirit — both must agree.
  test/         42 tests. The contact-isolation ones are load-bearing.
  tools/        The prototype, the copy extractor, and the sprite generators.
```

## The firmware

`variants/business-card-v1/firmware/production-pond/` — a **new** PlatformIO
env. `production` and `production-nfc` are never touched.
