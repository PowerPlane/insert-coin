# business-card-v1 enclosure

Placeholder for the 3D-printable sleeve / display holder. Drop CAD files here as they're designed:

- `*.f3d` — Fusion 360 source files
- `*.step` — neutral CAD interchange (preferred for sharing)
- `*.stl` — slicer-ready meshes
- `*.3mf` — preferred print-job format (slicer settings travel with the geometry)

Likely first artifact: a thin cardboard-sleeve-style mailer holder that exposes the LED window and the coin-cell slot, so the card can be handed out without the cell pre-inserted.
